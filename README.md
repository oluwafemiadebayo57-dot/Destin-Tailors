# 🧵 Destin Tailors — Bespoke Menswear & Women's Fashion

A premium, fully responsive demo website built for **Destin Tailors**, a leading bespoke fashion brand based in Akure, Nigeria. 

This project was designed to showcase their luxury aesthetic, display their lookbook, and streamline the appointment booking process directly to their WhatsApp.

## ✨ Key Features

- **Luxury Navy & Gold Aesthetic:** A custom color palette designed to convey high-end tailoring and premium quality.
- **Fully Responsive:** Extensively tested to look perfect on small mobile phones, tablets, and large desktop monitors.
- **WhatsApp Lead Generation:** A seamless contact form that pre-fills a WhatsApp message with the client's name, requested service (e.g., Bespoke Suit, Alterations), preferred date, and notes.
- **Curated Lookbook:** A dynamic CSS Grid gallery that adapts from a mosaic layout on desktop to a clean, single-column feed on mobile.
- **Zero Dependencies:** Built with pure, vanilla HTML, CSS, and JavaScript. No build tools required.
- **Scroll Animations:** Lightweight intersection observer animations to reveal content as the user scrolls.

## 🛠️ Tech Stack

- **HTML5** (Semantic structure)
- **CSS3** (Custom properties, CSS Grid, Flexbox)
- **Vanilla JavaScript** (Form logic, mobile menu, scroll reveals)
- **Cloudinary** (Image hosting/CDN)
- **Google Fonts** (Cormorant Garamond & Jost)
